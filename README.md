# Pomodoro Focus — Deep Work Timer

A feature-rich, single-file Pomodoro focus website with best-in-class UI and functionality. Customize durations, track stats, ambient sounds, gamification, analytics, music, and co-focus rooms.

## Features
- Focus / Short Break / Long Break timer with circular progress ring
- Customizable durations, auto-switch, auto-start, daily goals
- Task management with pomodoro estimates
- Stats, streaks, weekly chart, 12-week heatmap, best hours, CSV export
- Ambient sounds (rain, forest, café, ocean, white noise) with volume control
- Gamification: XP, levels, coins, 10 badges, theme shop
- Music integration (presets + custom YouTube/Spotify embeds)
- Co-Focus rooms via WebRTC (PeerJS) with timer sync and chat
- Breathing exercise, focus mode, keyboard shortcuts
- Light/dark themes, 10 accent colors, responsive, localStorage persistence

## Usage
Open `index.html` in any modern browser. No build step required.
